# T4 课后作业最小包（半页）

目标（大纲 v3.2 · 模块 8 扩展练习）：给自己（或家人）设一个月预算，记至少一笔真实支出，并能让别人用链接看只读总览。

## 1. 打开

- **优先公网：** https://glacial-violet-k6ck.here.now/  
  （若打不开，用本文件夹 `index.html`：同目录执行 `python3 -m http.server 8084` 后浏览器打开提示地址。）
- **不要**把 `127.0.0.1` / localhost 发给外网同学。

## 2. 最少改一处（三选一即可）

| 方式 | 最少做什么 |
|------|------------|
| A 页面改预算 | 「预算」→ 改账本名 + 月预算总额 →「保存预算」 |
| B 记一笔 | 「记一笔」→ 填真实金额/分类/日期 →「保存支出」 |
| C 改示范数据 | 打开 `index.html`，搜索 `【改这里②】`，改 `BUILTIN` 里的 `budget` 或一条 `expenses` |

作业演示：预算设好 + **至少 1 笔**自己的支出即可。分享建议 ≤40 笔。

## 3. 交什么

请提交下面 **三项**（截图或文字均可）：

1. **总览截图**（能看到预算 / 已花 / 剩余与进度条）
2. **分享链接或备份**（公网下「复制分享链接（#b=）」；或「导出 JSON」文件名）
3. **一句话说明**（给谁用，例如：「本月生活费给自己盯预算」）

可选加分：家人用无痕窗口打开 `#b=` 只读链接的截图。
