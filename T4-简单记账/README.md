## 本地打开（备选，同 WiFi 演示）

先进入本文件夹，再启动：

```bash
python3 -m http.server 8084
```

浏览器打开本机提示的地址。**不要把 `127.0.0.1` 发给外网同学**（只有你自己电脑打得开）。同 WiFi 可用电脑局域网 IP；正式分享请用公网地址。

## 白话使用说明

1. **总览**：大字看预算、已花、剩余；进度条超支变红；列表可删支出。
2. **记一笔**：金额、分类、日期、备注 → 保存。
3. **预算**：账本名 + 月预算总额；可「载入示范账本」。
4. **备份**：导出 / 导入 JSON，或「复制本机备份」文本。
5. **分享**：在公网地址下复制 `#b=` 只读链接；同学打开只能看，不能改你的本机账本。

## 已知限制

- 账本只存在本机浏览器；换设备请用导出 JSON 或 `#b=` 只读分享。
- `#b=` 分享是快照只读，对方改不了你的本机数据。
- 分享链接过长可能被聊天软件截断；笔数宜精简。
- 直接用 `file://` 打开一般也能用（不依赖外置脚本）。
