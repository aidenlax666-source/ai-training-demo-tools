# 提示词模板（帮你用 AI 生成账本 JSON）

把下面模板粘给 ChatGPT / Claude / 通义等，生成后导入本工具。

---

## 模板 A：按月生活费生成示范账本

```
你是家庭理财助手。请根据以下描述，生成简单记账 JSON。
要求：
- 输出纯 JSON，不要 markdown 代码块以外的文字
- 格式：{"title":"账本名","budget":数字,"expenses":[{"id":"e1","amount":数字,"category":"餐饮|交通|购物|居住|娱乐|学习|医疗|其他","note":"备注","date":"YYYY-MM-DD"}]}
- 共 8～12 笔，金额合理，日期落在同一个月
- 适合普通人日常开销

描述：
（在这里写：城市、月预算、家庭人数、有无车贷等）
```

---

## 模板 B：从流水文字整理

```
把下面消费流水整理成记账 JSON：
字段 title, budget, expenses[{id, amount, category, note, date}]
流水：
10/12 午饭 28
10/12 地铁 6
10/13 超市 126
…
月预算：3000
账本名：10月生活费
```

---

## 模板 C：分类汇总说明（给人看，不是导入）

```
根据下面 expenses JSON，用白话写一段「本月花在哪」总结（200 字内），并指出超支风险。
```

---

生成后：打开本工具 →「备份/分享」→「从文本导入」粘贴 JSON。
