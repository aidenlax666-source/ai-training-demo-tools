# 使用说明（白话）

## 推荐：公网打开

1. 用手机或电脑浏览器打开 `公网链接.txt` / README 里的**正式公网地址**。
2. 首页「总览」大字显示：月预算、已花、剩余，还有进度条（超支会变红）。
3. 「记一笔」填金额、分类、日期、备注 → 保存。
4. 「预算」里改账本名和月预算总额。
5. 「备份/分享」可导出 JSON，或复制 `#b=` 只读总览链接给家人看。  
   **务必在公网地址下复制**；若页面顶部出现橙色警告，说明你还在 localhost。

## 检查清单（分享前）

- [ ] 地址栏不是 `127.0.0.1` / `localhost`
- [ ] 或已在「分享基址」填好公网地址
- [ ] 笔数建议 ≤40（链接过长可能被截断）
- [ ] 用无痕窗口自己点开分享链接试一次（应为只读总览）

## 本地备选（同 WiFi）

1. 先进入本文件夹。
2. 执行：`python3 -m http.server 8084`
3. 本机浏览器打开提示的地址自测。
4. 给同 WiFi 手机用时，把 `127.0.0.1` 换成电脑的局域网 IP。  
   **不要把本机地址发给外网同学。**

### 手机查电脑局域网 IP（备选）

1. 电脑与手机连同一 WiFi。
2. 电脑看 IP：Mac「系统设置 → 网络」；Windows `ipconfig` 看 IPv4。
3. 手机浏览器打开 `http://电脑IP:8084/`。

## 四个页签做什么

| 页签 | 作用 |
|------|------|
| 总览 | 预算/已花/剩余、进度条、支出列表（可删） |
| 记一笔 | 新增一笔支出 |
| 预算 | 设账本名与月预算；可载入示范 |
| 备份/分享 | 导出/导入 JSON、复制备份文本、`#b=` 只读分享 |

## 数据存在哪

- 账本：本机 `localStorage`（换浏览器/清缓存会丢，请导出 JSON 备份）
- 分享链接：账本编码在网址 `#b=` 里（对方只读，不会改你的本机数据）
