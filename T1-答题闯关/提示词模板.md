# 提示词模板（给学员复制给 AI 用）

把下面整段复制到 ChatGPT / Claude / 豆包等，按需改【】里的内容。

---

## 模板 1：按知识点出一套选择题

```
我在做网页答题闯关小工具。请按下面要求出题，输出格式严格为「每行一题」：
题干|正确答案|错误选项1|错误选项2|错误选项3

知识点：【小学三年级：分数的初步认识】
题数：【10】
难度：【基础，适合刚学完的孩子】
不要出现超纲内容。只要题目列表，不要解释。
```

---

## 模板 2：改成英语单词闯关

```
请把下面口算题改成「英语单词选义」题，格式仍是：
英文单词|正确中文|错误中文1|错误中文2|错误中文3

词汇范围：【人教版七年级上册 Unit 1～2】
出【12】题。只要题目行，不要编号和讲解。
```

---

## 模板 3：从课文生成填空题

```
根据下面这段课文，出【8】道填空题，格式：
题干（用____表示空）|答案

课文：
【在这里粘贴课文】

答案要简短（词语或短句）。每行一题。
```

---

## 模板 4：改 questions.json

```
这是我的 questions.json 片段。请只改 customBank，换成【中国地理常识】10 题，
保持 JSON 合法，字段仍是 q / a / options（options 含正确答案共 4 个）。
不要改 templates 部分。直接输出完整可替换的 customBank 数组。
```

---

## 模板 5：加一种新题型（进阶）

```
我有一个单文件答题网页 index.html，现在支持选择题和填空题。
请教我：如果要加「判断题（对/错）」：
1. 自定义粘贴格式建议怎么定？
2. 需要改 parseCustomText 和 renderQuestion 的哪几处？
用白话说明，并给出最小改动代码片段。不要重写整个文件。
```

---

## 模板 6：换皮肤

```
我的答题闯关页用 CSS 变量：--primary、--success、--bg 等。
请给一套「清新绿色、适合小学生」的颜色值列表，我好直接替换 :root 里的变量。
只要变量名和色值，不要改 HTML 结构。
```

---

## 模板 7：页面内「知识库·AI」用的系统提示（对照用）

页面里已经内置类似提示。若你在外部 ChatGPT 先出题再粘贴回「自定义题目」，可用：

```
只根据下面知识库出题，不要编造知识库没有的事实。
题数：【5】。题型：【混合选择题与填空题】。
严格只输出 JSON 数组，不要 markdown 围栏：
[{"q":"题干","a":"正确答案","options":["正确","错1","错2","错3"]}]
填空题省略 options。答案要简短。

【知识库】
【在这里粘贴资料】
```

把输出的 JSON 转成「每行 `题干|答案|干扰项`」后，粘贴到网页「自定义题目」即可。

请用白话列排查清单，不要写攻击或绕过安全策略的方法。
