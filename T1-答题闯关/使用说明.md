# 使用说明（白话）

> 面向成年学员 · 大纲 **v3.2** · 公网以 `公网链接.txt` / 项目包 `00-链接与认领速查.md` 为准。

## 一、怎么打开（优先公网）

**课堂正式链接：** https://zippy-scroll-ac8c.here.now/

用手机或电脑浏览器直接打开即可玩、分享、看排行。

> 匿名站点约 **北京时间 2026-10-20 07:59** 前有效（以认领页为准）。  
> 认领永久站：https://here.now/c/4G5lu9L01pF_T-1v  
> 认领后可启用跨设备云端排行榜；未认领时成绩先存本机。

### 本地备选（同 WiFi / 自己改代码时）

1. 进入**本文件夹**（与 `index.html` 同级），执行：
   ```bash
   python3 -m http.server 8081
   ```
2. 浏览器打开终端里提示的本机地址。  
   **不要把 `127.0.0.1` 复制发给外网同学**（他们打不开）。外网分享请用上面的公网链接。
3. 同 WiFi 给手机玩：用电脑的局域网 IP（如 `http://192.168.x.x:8081/`），不要用 127.0.0.1。

## 二、怎么出题

### 方法 A：一键口算（最快）

1. 点 **「家长出题」**（出题页入口）
2. 选模板：10以内加法 / 20以内加减 / 九九乘法
3. 题数建议演示用 **3～5**；正式分享 **≤15**（本页已限制上限 15）
4. 点 **「生成并载入」**

### 方法 B：粘贴自己的知识点

1. 出题页切到 **「自定义题目」**
2. 每行一题：
   - 选择题：`题干|正确答案|错误1|错误2`
   - 填空题：`题干|答案`
3. 点 **「生成并载入」**（超过 15 题会自动截取前 15 题）

### 方法 C：改 JSON 文件

1. 用编辑器打开同目录的 `questions.json`
2. 改 `customBank`
3. 用本地服务器打开页面 → **「JSON题库」** → **「载入 JSON 示例题库」**

### 方法 D：知识库 + AI 出题

1. 出题页切到 **「知识库·AI」**
2. 给知识库起名，粘贴资料，或上传 `.txt` / `.md`
3. 点 **「保存到本机」**（可保存多份，选用/删除）
4. **API Key 可选**：
   - 有 Key：填 **API Base**（默认 DeepSeek）、**API Key**、**模型名** → 点 **「AI 根据知识库出题」**
   - Key 只存在本机浏览器，**不会写进分享链接、也不会提交到 Git**
   - 没有 Key / 接口失败：点 **「无 Key 规则出题」**，从资料切句生成简单题，照样能演示流程
5. 题数 3～15；资料超过约 6000 字时，送模型会自动截断并提示

> 分享出去的链接**只含生成好的题目**，不含知识库全文，也不含 API Key。

## 三、怎么分享

1. **请先用公网链接打开本站**（或在「分享基址」填公网地址）
2. 出好题后，点 **「复制分享链接」**
3. 发到微信/班级群；对方打开即可同一套题闯关
4. 题量已限制 **≤15**，避免链接过长被截断
5. **禁止**把 `127.0.0.1` / localhost 当外网分享链接

## 四、怎么玩

1. 首页点 **「开始闯关」** → 填昵称 → **开始**（不填昵称会以「匿名选手」上榜）
2. 选择题点选项；填空题输入后提交
3. 做完看分数；可进 **排行榜 / 错题回顾**（错题会显示你的答案与正确答案）

## 五、排行榜与错题

1. **错题回顾**：本局答错的题 + 你的答案 + 正确答案（存在本机会话）
2. **排行榜**：
   - 优先拉云端（认领站点后，同学跨手机可见）
   - 云端不可用时自动显示本机榜，并提示「云端排行暂不可用，已存本机」
3. 清空按钮只清**本机**本套题成绩，不清云端

## 六、常见问题

| 现象 | 处理 |
|------|------|
| 「开始闯关」是灰的 | 先出题，或打开带 `#q=` 的分享链接 |
| 复制链接被拒绝 / 提示本地不能发 | 改用公网 `https://zippy-scroll-ac8c.here.now/` 打开后再复制，或填分享基址 |
| 对方看不到你的分数 | 站点未认领时只有本机榜；认领后云端才跨设备同步 |
| JSON 载入失败 | 本地须用 `python3 -m http.server`，不要用 file:// |
| AI 出题提示 CORS / 网络失败 | 该接口可能不允许浏览器直连；换 DeepSeek，或用「规则出题」 |
| AI 出题 401 | Key 填错或过期，重新复制 Key |
| 担心 Key 泄露 | Key 只在本机 localStorage；分享链接不含 Key；不要把 Key 写进代码仓库 |
| 上传知识库失败 | 请用 `.txt` 或 `.md` 文本文件 |
