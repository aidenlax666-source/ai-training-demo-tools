# 使用说明（白话）

## 一、怎么打开（优先公网）

**课堂正式链接：** https://lively-mirage-sh6f.here.now/

用手机或电脑浏览器直接打开即可玩、分享、看排行。

> 匿名站点约 **北京时间 2026-10-18 20:08** 前有效。认领永久站：https://here.now/c/7fuoThG6YrqDod-k  
> 认领后可启用跨设备云端排行榜；未认领时成绩先存本机。

### 本地备选（同 WiFi / 自己改代码时）

1. 进入**本文件夹**（与 `index.html` 同级），执行：
   ```bash
   python3 -m http.server 8081
   ```
2. 浏览器打开终端里提示的本机地址。  
   **不要把 `127.0.0.1` 复制发给外网同学**（他们打不开）。外网分享请用上面的公网链接。
3. 同 WiFi 给手机玩：用电脑的局域网 IP（如 `http://192.168.x.x:8081/`），不要用 127.0.0.1。

## 二、家长怎么出题

### 方法 A：一键口算（最快）

1. 点 **「家长出题」**
2. 选模板：10以内加法 / 20以内加减 / 九九乘法
3. 题数建议演示用 **3～5**；正式分享建议 **≤15**（链接更短）
4. 点 **「生成并载入」**

### 方法 B：粘贴自己的知识点

1. 出题页切到 **「自定义题目」**
2. 每行一题：
   - 选择题：`题干|正确答案|错误1|错误2`
   - 填空题：`题干|答案`
3. 点 **「生成并载入」**

### 方法 C：改 JSON 文件

1. 用编辑器打开同目录的 `questions.json`
2. 改 `customBank`
3. 用本地服务器打开页面 → **「JSON题库」** → **「载入 JSON 示例题库」**

## 三、怎么分享给同学

1. **请先用公网链接打开本站**（不要用本地 127.0.0.1）
2. 出好题后，点 **「复制分享链接」**
3. 发到微信/班级群；同学打开即可同一套题闯关
4. 题目超过 15 道时，页面会提醒链接很长——建议减到 ≤15 再分享

## 四、孩子怎么玩

1. 首页点 **「开始闯关」** → 填昵称 → **开始**
2. 选择题点选项；填空题输入后提交
3. 做完看分数；可进 **排行榜 / 错题回顾**

## 五、排行榜与错题

1. **错题回顾**：本局答错的题 + 正确答案（存在本机会话）
2. **排行榜**：
   - 优先拉云端（认领站点后，同学跨手机可见）
   - 云端不可用时自动显示本机榜，并提示「云端排行暂不可用，已存本机」
3. 清空按钮只清**本机**本套题成绩，不清云端

## 六、常见问题

| 现象 | 处理 |
|------|------|
| 「开始闯关」是灰的 | 先出题，或打开带 `#q=` 的分享链接 |
| 复制链接被拒绝 / 提示本地不能发 | 改用公网 `https://lively-mirage-sh6f.here.now/` 打开后再复制 |
| 同学看不到你的分数 | 站点未认领时只有本机榜；认领后云端才跨设备同步 |
| JSON 载入失败 | 本地须用 `python3 -m http.server`，不要用 file:// |
