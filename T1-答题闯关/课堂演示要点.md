# 课堂演示要点（3～5 分钟）

## 开场（20 秒）

> 「这是一个家长出题、孩子闯关、同学用链接比分的网页小游戏。不用安装 App，浏览器打开就能玩。」

**优先打开公网正式链接：**

https://lively-mirage-sh6f.here.now/

（本地备选：在本文件夹执行 `python3 -m http.server 8081`，用本机提示地址打开；**不要把 127.0.0.1 发给学员。**）

---

## 演示脚本

### ① 家长一键出题（约 1 分钟）

1. 点 **「家长出题」**
2. 点选 **「九九乘法」**（或 10 以内加法）
3. 题数改成 **3～5**（演示快，分享链接也短）
4. 点 **「生成并载入」**
5. **强调：**「题目已经进网页了，首页能看到当前题库。」

### ② 复制分享链接（约 40 秒）

1. 确认当前是**公网**地址再点 **「复制分享链接」**
2. 新开隐私/无痕窗口，粘贴打开
3. **强调：**「链接里带着题库（`#q=`），同学打开就是同一套卷。」

### ③ 孩子闯关 + 对错反馈（约 1.5 分钟）

1. 填昵称「小红」→ **开始**
2. 故意答错一题 → 指出红色反馈和正确答案
3. 再答对一题 → 指出得分增加
4. 把 **3～5 题** 做完看成绩（时间够就完整走完，不必跳题）

### ④ 排行榜与错题（约 40 秒）

1. 结果页进 **排行榜 / 错题回顾**
2. 指排行：昵称、分数、用时；说明云端认领后可跨手机
3. 指错题列表
4. **强调：**「未认领时成绩先存本机；认领永久站后云端榜可跨设备。」

### ④½ 知识库·AI（可选，约 40 秒）

1. 切到 **「知识库·AI」**，粘贴一小段资料
2. **不填 Key**，点「规则出题」→ 强调「没 Key 也能演示」
3. 有 Key 再点一次 AI 出题对比（可跳过）

### ⑤ 收尾：改成自己的（约 30 秒）

1. 打开 `改成自己的.md` 或 README 里的 3 步
2. 指着 `index.html` 里 **「改这里①主题色」**
3. 布置作业：用提示词模板让 AI 出 5～10 道本班知识点题，粘贴进自定义出题（分享建议 ≤15 题）

---

## 强调什么（板书可写）

1. **最小可用**：单文件 / 零构建 / 打开就能玩  
2. **分享靠公网链接**：`#q=` 编码题库；本地 127 不能当外网分享  
3. **排行**：本机兜底 + 认领后云端跨设备  
4. **学员能改**：题目、颜色、分数三处有中文标注  

## 时间不够就砍

- 砍 JSON 页演示  
- 闯关只做 **3 题**  
- 「改颜色」口头指一下即可
