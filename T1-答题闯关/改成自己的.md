# 改成自己的（严格 3 步）

适合零基础：只改标注的地方，别的先别动。面向成年学员（自己 / 家人 / 同事用）。

> 对应大纲 **v3.2 模块 6**：最少改一处 → 再演示。

---

## 第 1 步：改题目（换成你的知识点）

**你想要什么：** 英语单词、行业术语、岗位常识、古诗……

**改哪里（四选一）：**

### 方案 A — 改 JSON（推荐给「改文件」练习）

- 文件：`questions.json`
- 位置：`customBank` 数组
- 例子：
  ```json
  {
    "q": "苹果用英语怎么说？",
    "a": "apple",
    "options": ["apple", "banana", "orange", "grape"]
  }
  ```
- 保存后：用本地服务器打开 → 出题页 → JSON题库 → 载入  
- 分享建议一共 ≤15 题

### 方案 B — 改 HTML 内置配置

- 文件：`index.html`
- 搜索注释：`【改这里②】`
- 改 `CONFIG.customBank` 或 `CONFIG.templates`（口算参数：`op` / `max` / `count`）

### 方案 C — 不改文件，页面粘贴

- 打开网页 → 出题页 → 自定义题目 → 按 `题干|答案|干扰项` 粘贴 → 生成

### 方案 D — 知识库 + AI（推荐给「有资料、想自动出题」）

1. 打开网页 → 出题页 → **知识库·AI**
2. 粘贴/上传课文或笔记 → 保存知识库
3. **API Key 可选**：填 DeepSeek Key 用 AI；或点「规则出题」零 Key 演示
4. 复制**公网**分享链接（只含题目，不含 Key / 知识库全文）

**验收：** 首页出现「当前题库」，题来自你的资料内容，能开始闯关。

---

## 第 2 步：改皮肤与规则（颜色、字号、分数）

**改皮肤：**

- 文件：`index.html` 顶部 `<style>` 里
- 搜索：`【改这里①】主题色`
- 例如把 `--primary: #4f6ef7;` 改成 `#e11d48;`（玫红）

**改计分：**

- 同一文件，搜索：`【改这里③】计分规则`
- `scoreCorrect: 10` → 答对加几分
- `scoreWrong: 0` → 答错扣几分（可改成负数，如 `-2`）

**验收：** 刷新页面，按钮颜色变了；答一题看分数是否按新规则加。

---

## 第 3 步：改分享方式（了解现有机制）

**本版已有：** 题目打进网址 `#q=...`（Base64），复制链接即分享，无需服务器存题。

**你一般不用改代码。** 若课堂要演示「改分享」：

1. 打开 `index.html`，搜索函数 `encodeQuiz` / `copyShareLink`
2. 想改提示文案：改 `copyShareLink` 里 toast 的文字即可

**重要：**

- 分享必须用**公网地址**（如 `https://wistful-breath-ggw5.here.now/`），不要教别人用 localhost
- 本机调试时，在「分享基址」填公网地址再复制
- 云端比分：发布到 here.now 并认领站点后写入 Site Data；未认领则本机 `localStorage` 兜底
- 认领：https://here.now/c/1rAOWMay1id3C2OW

**验收：** 复制链接 → 新隐私窗口打开 → 自动出现同一套题。
