## 本地打开（备选，同 WiFi 演示）

先进入本文件夹，再启动：

```bash
python3 -m http.server 8081
```

浏览器打开本机提示的地址。**不要把 `127.0.0.1` 发给外网同学**。若要给同 WiFi 手机玩，用电脑的局域网 IP（见使用说明）。

## 白话使用说明

1. **出题**：选口算模板 / 粘贴自定义 / JSON，或打开 **「知识库·AI」** 粘贴资料后 AI/规则出题。
2. **AI 出题（可选）**：填 DeepSeek（或兼容接口）的 Base / Key / 模型；没有 Key 就用「规则出题」兜底。Key 只存在本机浏览器，不会进分享链接。
3. **分享**：优先复制公网分享链接；对方打开就是同一套题。禁止用 localhost 当外网分享。
4. **闯关**：填昵称 → 开始闯关 → 看结果与错题（含「你的答案」）。
5. **排行榜**：优先云端（认领后跨手机）；失败则本机兜底并提示。

## 怎么改题

| 方式 | 改哪里 |
|------|--------|
| 口算模板参数 | `index.html` 里 `CONFIG.templates`（「改这里②」） |
| 粘贴自定义 | 页面「自定义题目」 |
| JSON 题库 | 同目录 `questions.json` 的 `customBank` |
| 知识库 + AI | 页面「知识库·AI」：粘贴/上传资料 → AI 或规则出题 |

自定义格式（每行一题）：选择题 `题干|正确答案|错误1|错误2`；填空 `题干|答案`。

## 已知限制

- API Key / 知识库名单存在浏览器 `localStorage`，**不要提交 Key 到 Git**。
- 部分大模型接口可能禁止浏览器直连（CORS）；可用 DeepSeek 或「规则出题」兜底。
- 未认领 here.now 站点时，跨手机云端排行榜不可用。
- 匿名站点约 24 小时过期；请尽早打开认领链接永久保存。
- 「规则出题」是演示兜底，题目质量不如真 AI；正式课建议有 Key 或改用外部 AI + 粘贴自定义。
