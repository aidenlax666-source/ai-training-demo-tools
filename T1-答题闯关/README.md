# T1：口算/知识点答题闯关（网页版）

家长出题 →（可选）知识库 + AI 出题 → 孩子闯关 → 同学用同一链接比分。优先用**公网链接**分享。

## 课堂演示正式链接（公网）

**打开：** https://lively-mirage-sh6f.here.now/

1. 家长在页面出题（口算 / 自定义 / JSON / **知识库·AI**）
2. 点「复制分享链接」发给同学（链接里带 `#q=` 题库；**不含 API Key、不含知识库全文**）
3. 同学用手机/电脑浏览器打开即可闯关；本机可看排行榜与错题回顾

> 当前为匿名托管，约 **北京时间 2026-10-18 20:08** 前有效。认领永久站：https://here.now/c/7fuoThG6YrqDod-k  
> 题很多时链接会变长，建议单次分享 **≤15 题**。

## 本地打开（备选，同 WiFi 演示）

先进入本文件夹，再启动：

```bash
python3 -m http.server 8081
```

浏览器打开本机提示的地址。**不要把 `127.0.0.1` 发给外网同学**（只有你自己电脑打得开）。若要给同 WiFi 手机玩，用电脑的局域网 IP（见使用说明）。

## 白话使用说明

1. **家长出题**：选口算模板 / 粘贴自定义 / JSON，或打开 **「知识库·AI」** 粘贴资料后 AI/规则出题。
2. **AI 出题**：在页面填 DeepSeek（或兼容接口）的 Base / Key / 模型；Key 只存在本机浏览器，不会进分享链接。
3. **分享**：优先复制公网分享链接；对方打开就是同一套题。
4. **孩子玩**：填昵称 → 开始闯关 → 看结果与错题。
5. **排行榜**：优先云端（认领后跨手机）；失败则本机兜底并提示。

## 怎么改题

| 方式 | 改哪里 |
|------|--------|
| 口算模板参数 | `index.html` 里 `CONFIG.templates`（「改这里②」） |
| 粘贴自定义 | 页面「自定义题目」 |
| JSON 题库 | 同目录 `questions.json` 的 `customBank` |
| 知识库 + AI | 页面「知识库·AI」：粘贴/上传资料 → AI 或规则出题 |

自定义格式（每行一题）：选择题 `题干|正确答案|错误1|错误2`；填空 `题干|答案`。

## 已知限制

- API Key / 知识库名单存在浏览器 `localStorage`，**不要提交 Key 到 Git**。
- 部分大模型接口可能禁止浏览器直连（CORS）；可用 DeepSeek 或「规则出题」兜底。
- 未认领 here.now 站点时，跨手机云端排行榜不可用。
