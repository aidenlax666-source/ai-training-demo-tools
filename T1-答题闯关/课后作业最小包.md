# T1 课后作业最小包（半页）

目标：自己改最少几道题，发出去能让别人打开闯关。不要求接真 AI。

## 1. 打开

- **优先公网：** https://lively-mirage-sh6f.here.now/  
  （若打不开，用仓库里本文件夹的 `index.html`：同目录执行 `python3 -m http.server 8081` 后浏览器打开提示地址。）
- **不要**把 `127.0.0.1` / localhost 发给外网同学。

## 2. 改最少几道题（三选一即可）

| 方式 | 最少做什么 |
|------|------------|
| A 口算 | 「家长出题」→ 选模板 → 题数 **3～5** →「生成并载入」 |
| B 自定义 | 「自定义题目」粘贴 **至少 3 行**（选择题：`题干\|正确\|错1\|错2`；填空：`题干\|答案`）→「生成并载入」 |
| C 知识库 | 「知识库·AI」粘贴一小段资料 →「无 Key 规则出题」（不必填 API Key） |

题量分享上限 **≤15**；作业演示用 3～5 题即可。

## 3. 交什么

请提交下面 **三项**（截图或文字均可）：

1. **分享链接**（公网地址下点「复制分享链接」得到的 `#q=` 链接；同学能打开同一套题）
2. **题目截图或原文**（你改的至少 3 道题）
3. **一句话说明**（给谁用 / 考什么，例如：「给孩子练 10 以内加法」）

可选加分：自己做完一局，交一张得分或错题回顾截图。

## 提醒

- 分享链接只含题目，不含知识库全文、不含 API Key。  
- 匿名公网站点约 24 小时；长期演示请认领：https://here.now/c/7fuoThG6YrqDod-k  
- 更细步骤见同目录《使用说明.md》。
