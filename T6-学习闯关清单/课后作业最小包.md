# T6 课后作业最小包（学员可复制）

> 半页交作业说明。**面向成年学员**；网页示范，最少改一处即可交差。

## 1. 怎么打开

优先用公网（课堂演示链，匿名有有效期，过期看开班通知 / 仓库 README）：

https://minty-cottage-8xs3.here.now/

备选：进入文件夹 `T6-学习闯关清单`，执行 `python3 -m http.server 8086`（Windows 可用 `py -m http.server 8086`），用浏览器打开本机地址。**不要把 `127.0.0.1` 发给外网同学。**

## 2. 最少改一处（做成你自己的）

任选其一即可：

- **页面里改**：打开「新建/编辑」，改 **1 个关卡名**，或给某一关增删 **1 条**任务  
- **或改文件**：打开 `quests.json`，改一处任务文案后，在「备份/分享」里导入

示范清单是「AI 上手 · 五关清单」（建议 7 天完成 · 共 5 关），请改成与你工作/学习相关的主题。

## 3. 交什么（两张截图即可）

1. **闯关截图**：总进度条 + 你改过的那一关（勾选至少 1 项任务）  
2. **分享截图**：「备份/分享」面板，或已复制的分享链接（课堂丢群可用「精简前 4 关」；无痕打开若关卡不全 = 链接被截断，改交导出 JSON 截图）

文件名建议：`姓名_T6_闯关.png`、`姓名_T6_分享.png`。

## 可选加分

用无痕窗口自测分享链接；或导出 JSON 备份文件一并提交。
