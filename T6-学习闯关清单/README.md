# T6：学习闯关清单（网页版）

把一门小课程拆成若干「关卡」，每关勾选任务；看总进度；进度存在本机；可把清单编进链接分享给同学。优先用**公网链接**打开与分享。

## 课堂演示正式链接（公网）

**打开：** https://silver-orbit-5rcs.here.now/

1. 打开页面 → 直接闯示范「7 天 AI 上手闯关」
2. 勾选任务；完成一关会有庆祝，并解锁下一关（可关「推荐顺序解锁」）
3. 「备份/分享」→「复制分享链接」发给同学（链接带 `#q=` 清单结构）

> 当前为匿名托管，约 **北京时间 2026-10-18 20:29** 前有效。认领永久站：https://here.now/c/2z45dQqzM296AgvQ  
> 关卡很多时链接会变长，建议单次分享 **≤6 关**。

## 本地打开（备选，同 WiFi 演示）

先进入本文件夹，再启动：

```bash
python3 -m http.server 8086
```

浏览器打开本机提示的地址。**不要把 `127.0.0.1` 发给外网同学**（只有你自己电脑打得开）。同 WiFi 可用电脑局域网 IP；正式分享请用公网地址。

## 白话使用说明

1. **闯关**：看总进度条；点开关卡勾选任务；完成一关会庆祝并解锁下一关。
2. **新建/编辑**：改清单名、增删关卡与任务（每行一条任务）。
3. **备份**：导出 / 导入 JSON；可另导进度；可「清空本机勾选」。
4. **分享**：在公网地址下复制 `#q=` 链接；同学打开是同一套关卡，勾选存在各自本机。

## 「改成自己的」3 步（速查）

1. **改内容**：页面新建关卡，或改 `quests.json` 后导入。
2. **改皮肤**：`index.html` 顶部 CSS 变量 `--primary`（注释 `【改这里①】`）。
3. **改分享**：发布到公网后，把新链接写进本 README 与 `公网链接.txt`。

更细：`使用说明.md` · `改成自己的.md` · `课堂演示要点.md` · `提示词模板.md`

## 文件列表

- `index.html` — 可运行成品（单文件）
- `quests.json` — 可改示范清单
- `公网链接.txt` — 当前公网 URL / 认领链接

## 已知限制

- 勾选进度只存在本机浏览器，**不会**随 `#q=` 分享链接带走（这是故意的）。
- 分享链接过长可能被聊天软件截断；关卡宜精简（≤6 关）。
- 直接用 `file://` 打开时可能读不到 `quests.json`（内置示范与 `#q=` 分享仍可用）。
