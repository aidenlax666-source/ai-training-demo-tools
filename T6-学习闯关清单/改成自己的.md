## 第 1 步：改关卡内容

**方案 A — 页面里加（最快）**

1. 打开网页 →「新建/编辑」
2. 填关卡名称、说明，任务每行一条 →「添加关卡」
3. 或编辑已有关 →「保存本关」

**方案 B — 改 `quests.json`（适合练改文件）**

```json
{
  "title": "本周学习关卡",
  "quests": [
    {
      "id": "q1",
      "name": "第 1 关 · 开场",
      "desc": "先热身",
      "tasks": [
        { "id": "t1", "text": "读完使用说明" },
        { "id": "t2", "text": "勾选本条任务试一下" }
      ]
    }
  ]
}
```

保存后：用本地服务器打开本文件夹 →「备份/分享」→「导入 JSON」选这个文件；或把内容粘进「从文本导入」。

**方案 C — 改 HTML 内置示范**

- 打开 `index.html`，搜索注释：`【改这里②】`
- 改 `BUILTIN.quests` 数组
