## 推荐：公网打开

1. 用手机或电脑浏览器打开 **https://subtle-quartz-28bx.here.now/**（或 `公网链接.txt` / README）。
2. 首页「闯关」显示示范「AI 上手 · 五关清单」，副标题「建议 7 天完成 · 共 5 关」；看已完成任务、总数、百分比与进度条。
3. 点开某一关 → 勾选任务；全部勾完会提示通关，并解锁下一关。
4. 「新建/编辑」可改清单名、加关、改任务。
5. 「备份/分享」可导出 JSON，或复制 `#q=` 分享链接给同学；课堂丢群可用「复制精简分享（前 4 关）」。  
   **务必在公网地址下复制**；若页面顶部出现橙色警告，说明你还在 localhost。

## 检查清单（分享前）

- [ ] 地址栏不是 `127.0.0.1` / `localhost`
- [ ] 或已在「分享基址」填好公网地址
- [ ] 关卡宜精简；**以 URL 总长为准**（≤6 关仍可能因任务文案长而超长；页面超过约 2000 字符会警告）
- [ ] 用**无痕 / 无痕窗口**自己点开分享链接试一次（应看到同一套关卡，勾选是空的）
- [ ] 若无痕打开后关卡不全 = 链接被截断 → 改导出 JSON，或删减关卡 / 用「精简前 4 关」后再分享

## 本地备选（同 WiFi）

1. 先进入本文件夹。
2. 执行：`python3 -m http.server 8086`（Windows 也可 `py -m http.server 8086`）
3. 本机浏览器打开提示的地址自测。
4. 给同 WiFi 手机用时，把 `127.0.0.1` 换成电脑的局域网 IP。  
   **不要把本机地址发给外网同学。**

### 手机查电脑局域网 IP（备选）

1. 电脑与手机连同一 WiFi。
2. 电脑看 IP：Mac「系统设置 → 网络」；Windows `ipconfig` 看 IPv4。
3. 手机浏览器打开 `http://电脑IP:8086/`。

## 三个页签做什么

| 页签 | 作用 |
|------|------|
| 闯关 | 总进度、关卡列表、勾选任务、顺序解锁 |
| 新建/编辑 | 改清单名、增删改关卡与任务、载入示范 |
| 备份/分享 | 导出/导入 JSON、清空勾选、`#q=` 分享（含精简前 4 关）|

## 数据存在哪

- 清单结构 + 勾选进度：本机 `localStorage`（换浏览器/清缓存会丢，请导出 JSON 备份）
- 分享链接：清单结构编码在网址 `#q=` 里（**不含**勾选进度）
