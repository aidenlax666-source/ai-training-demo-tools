# 提示词模板（帮你用 AI 生成关卡 JSON）

把下面模板粘给 ChatGPT / Claude / 通义等，生成后导入本工具。

> 本工具示范名是「AI 上手 · 五关清单」（建议 7 天完成 · 共 5 关）。生成时请让 title 与关卡数一致，勿写成「每天一关共七关」却只出 5 关。

---

## 模板 A：按主题生成闯关清单

```
你是成人培训助教。请根据以下主题，生成「学习闯关清单」JSON。
要求：
- 输出纯 JSON，不要 markdown 代码块以外的文字
- 格式：{"title":"清单名","quests":[{"id":"q1","name":"第 1 关 · 标题","desc":"一句话说明","tasks":[{"id":"t1","text":"可执行的白话任务"}]}]}
- 共 4～6 关，每关 3～5 项任务
- 任务要具体、可勾选、适合零基础成年人（避免术语堆砌）
- 不要依赖必须上网或付费工具才能完成的任务

主题：
（在这里写：例如「一周学会用 AI 写周报」或「摄影入门 5 关」）
```

---

## 模板 B：从大纲整理成关卡

```
把下面课程大纲整理成闯关清单 JSON：
字段 title, quests[{id, name, desc, tasks[{id, text}]}]
大纲：
1. …
2. …
…
清单名：本周学习关卡
每关任务 3～4 条，白话可执行
```

---

## 模板 C：把已有清单改得更可执行（给人看，也可再导入）

```
下面是一份 quests JSON。请把每条任务改写得更具体（仍保持 JSON 结构），字数适中，适合课堂 1 周完成。
```

---

生成后：打开本工具 →「备份/分享」→「从文本导入」粘贴 JSON。
