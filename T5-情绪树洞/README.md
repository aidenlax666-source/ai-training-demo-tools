# T5：情绪树洞（把心里话写下来）

把心里话按心情写下来，只存在本机；可筛选浏览、导出备份，也可把记录编进链接做只读分享。优先用**公网链接**打开与分享。

**面向成年学员的培训示范；不适合高中生及以下单独使用。**

**明确不是**心理咨询、诊断或 AI 聊天机器人。**永久口径：不能替代心理咨询/诊断。**

> 课程嵌入（大纲 **v3.2**）：主要在 **模块 8**「扩展改自己的」；**永久口径：不能替代心理咨询/诊断。** 链接以项目包 `00-链接与认领速查.md` 为准。

## 本地打开（备选，同 WiFi 演示）

先进入本文件夹，再启动：

```bash
python3 -m http.server 8085
```

浏览器打开本机提示的地址。**不要把 `127.0.0.1` 发给外网同学**（只有你自己电脑打得开）。同 WiFi 可用电脑局域网 IP；正式分享请用公网地址。

## 白话使用说明

1. **树洞**：选心情标签、写正文、日期（默认今天）、可选标题 → 保存。
2. **我的记录**：新→旧列表；可按心情筛选；可展开看全文、删除单条。
3. **备份**：导出 / 导入 JSON，或「复制本机备份」文本。
4. **分享**：在公网地址下勾选记录，复制 `#e=` 只读链接；同学打开只能看，不能改你的本机数据。

## 「改成自己的」3 步（速查）

1. **改内容**：页面写记录，或改 `index.html` 里 `BUILTIN` / 导入 `entries.json`。
2. **改皮肤**：`index.html` 顶部 CSS 变量 `--primary`。
3. **改分享**：发布到公网后，把新链接写进本 README 与 `公网链接.txt`。

更细：`使用说明.md` · `改成自己的.md` · `课堂演示要点.md` · `提示词模板.md`

## 文件列表

- `entries.json` — 可改示范记录
- `公网链接.txt` — 当前公网 URL / 认领链接

## 已知限制

- 记录只存在本机浏览器；换设备请用导出 JSON 或 `#e=` 只读分享。
- `#e=` 分享是快照只读，对方改不了你的本机数据。
- 分享链接过长可能被聊天软件截断；笔数宜精简（≤30）。条少文长也会超长（>2000 字符），优先导出 JSON。
- 直接用 `file://` 打开一般也能用（不依赖外置脚本）。
- **不能替代专业心理帮助**；持续难受请寻求亲友或专业支持。
