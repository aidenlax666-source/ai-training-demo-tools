# 使用说明（白话）

## 推荐：公网打开

1. 用手机或电脑浏览器打开 `公网链接.txt` / README 里的**正式公网地址**。
2. 「树洞」选心情（平静/开心/焦虑…），写心里话，可选标题，日期默认今天 →「放进树洞」。
3. 「我的记录」可按心情筛选；点「展开」看全文；可删单条。
4. 「备份/分享」可导出 JSON，或勾选记录后复制 `#e=` 只读链接给信任的人看。  
   **务必在公网地址下复制**；若页面顶部出现橙色警告，说明你还在 localhost。

## 检查清单（分享前）

- [ ] 地址栏不是 `127.0.0.1` / `localhost`
- [ ] 或已在「分享基址」填好公网地址
- [ ] 笔数建议 ≤30（链接过长可能被截断）
- [ ] 用无痕窗口自己点开分享链接试一次（应为只读）
- [ ] 确认分享对象是你信任的人（心里话很私密）

## 本地备选（同 WiFi）

1. 先进入本文件夹。
2. 执行：`python3 -m http.server 8085`
3. 本机浏览器打开提示的地址自测。
4. 给同 WiFi 手机用时，把 `127.0.0.1` 换成电脑的局域网 IP。  
   **不要把本机地址发给外网同学。**

### 手机查电脑局域网 IP（备选）

1. 电脑与手机连同一 WiFi。
2. 电脑看 IP：Mac「系统设置 → 网络」；Windows `ipconfig` 看 IPv4。
3. 手机浏览器打开 `http://电脑IP:8085/`。

## 三个页签做什么

| 页签 | 作用 |
|------|------|
| 树洞 | 写一笔：心情、正文、日期、可选标题 |
| 我的记录 | 列表（新→旧）、按心情筛选、展开/删除 |
| 备份/分享 | 导出/导入 JSON、复制备份文本、`#e=` 只读分享 |

## 数据存在哪

- 记录：本机 `localStorage`（换浏览器/清缓存会丢，请导出 JSON 备份）
- 分享链接：记录编码在网址 `#e=` 里（对方只读，不会改你的本机数据）

## 重要提醒

本工具是培训示范，**不是心理咨询或诊断**。若情绪持续难受，请联系亲友或专业机构。
