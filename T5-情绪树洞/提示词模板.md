# 提示词模板（帮你用 AI 改自己的树洞）

把下面模板粘给 ChatGPT / Claude / 通义等，生成后导入本工具。

---

## 模板 A：生成示范情绪记录 JSON

```
你是温和的日记助手（不是心理咨询师）。请根据以下描述，生成情绪树洞 JSON。
要求：
- 输出纯 JSON，不要 markdown 代码块以外的文字
- 格式：{"entries":[{"id":"e1","mood":"平静|开心|焦虑|难过|愤怒|疲惫|感恩|其他","title":"可选标题","body":"正文","date":"YYYY-MM-DD"}]}
- 共 3～6 条，语气真诚、简短，适合普通人日常
- 不要给出诊断、药方或「你应该」的说教

描述：
（在这里写：最近想记录什么情绪、场合，例如「工作压力一周」「和家人相处」）
```

---

## 模板 B：把零散笔记整理成条目

```
把下面零散心里话整理成情绪树洞 JSON：
字段 entries[{id, mood, title, body, date}]
mood 只能是：平静、开心、焦虑、难过、愤怒、疲惫、感恩、其他
笔记：
10/14 今天好累，开会开到晚上……
10/15 午饭后晒太阳，心情好一点
…
```

---

## 模板 C：改主题色 / 文案（给 AI 改 index.html）

```
我有一个单文件情绪树洞网页（index.html）。请只改：
1. :root 里【改这里①】的颜色变量，改成更偏暖粉的风格
2. header 副标题文案，保持中文、零基础友好
不要改 localStorage key、不要改 #e= 编解码逻辑。
（粘贴 index.html 相关片段）
```

---

生成后：打开本工具 →「备份/分享」→「从文本导入」粘贴 JSON。
