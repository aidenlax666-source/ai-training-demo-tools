## 推荐：公网打开

1. 用手机或电脑浏览器打开正式公网地址：  
   **https://happy-oyster-v9he.here.now/**  
   （匿名约至北京时间 **2026-10-21 18:05**；认领：https://here.now/c/IZQclyLUM18GKjJx）
2. 首页默认是「学习」：点大卡片翻面，看正面问题 / 背面答案（示范为课程十模块要点，非英语单词）。
3. 点「记住了」或「再看」后会自动下一张（标记只保存在你这台设备）。
4. 要给对方同一套卡：打开「分享/导入」→「复制分享链接」→ 发给对方。  
   **务必在公网地址下复制**；若页面顶部出现橙色警告，说明你还在 localhost。

## 检查清单（分享前）

- [ ] 地址栏不是 `127.0.0.1` / `localhost`
- [ ] 或已在「分享基址」填好公网地址
- [ ] 卡组张数建议 ≤30
- [ ] 用无痕窗口自己点开分享链接试一次

## 本地备选（同 WiFi）

1. 先进入本文件夹。
2. 执行：`python3 -m http.server 8083`
3. 本机浏览器打开提示的地址（如 `http://127.0.0.1:8083/`）自测。
4. 给同 WiFi 手机用时，把 `127.0.0.1` 换成电脑的局域网 IP（手机设置 / 路由器 / 电脑网络里可查）。  
   **不要把本机地址发给外网同学。**

### 手机查电脑局域网 IP（备选）

1. 电脑与手机连同一 WiFi。  
2. 电脑看 IP：Mac「系统设置 → 网络」；Windows `ipconfig` 看 IPv4；或路由器设备列表。  
3. 手机浏览器打开 `http://电脑IP:8083/`。
