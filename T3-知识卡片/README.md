## 本地打开（备选，同 WiFi 演示）

先进入本文件夹，再启动：

```bash
python3 -m http.server 8083
```

浏览器打开本机提示的地址。**不要把 `127.0.0.1` 发给外网同学**（只有你自己电脑打得开）。同 WiFi 可用电脑局域网 IP；正式分享请用公网地址。

## 白话使用说明

1. **学习**：点卡片或「翻面」看答案；「记住了 / 再看」会记在本机；← → 换卡。
2. **卡组**：看列表、改卡组名、跳到某张学习、编辑或删除。
3. **新建/编辑**：填正面、背面、可选标签 → 保存。
4. **分享**：在公网地址下点「复制分享链接」；对方打开即同一套卡。
5. **导入导出**：导出 JSON 备份；导入 JSON / 粘贴文本可换卡组。

## 已知限制

- 「记住了 / 再看」只存在本机浏览器，不会随分享链接带走。
- 分享链接过长可能被聊天软件截断；卡组宜精简。
- 直接用 `file://` 打开时可能读不到 `cards.json`（内置示范与 `#c=` 分享仍可用）。
