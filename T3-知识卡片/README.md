# T3：知识卡片小工具（网页版）

正面提问、翻面看答案，可把整套卡组编进链接分享给同学。优先用**公网链接**打开与分享。

## 课堂演示正式链接（公网）

**打开：** https://pastel-oasis-an83.here.now/

1. 打开页面 → 可直接学示范「英语单词」卡组
2. 点「新建/编辑」加自己的卡片，或「卡组」里改名称
3. 点「分享/导入」→「复制分享链接」发给同学（链接带 `#c=` 卡组）

> 当前为匿名托管，约 **北京时间 2026-10-18 20:22** 前有效。认领永久站：https://here.now/c/8JXCmuS6jNFcfnI6  
> 卡很多时链接会变长，建议单次分享 **≤30 张**。

## 本地打开（备选，同 WiFi 演示）

先进入本文件夹，再启动：

```bash
python3 -m http.server 8083
```

浏览器打开本机提示的地址。**不要把 `127.0.0.1` 发给外网同学**（只有你自己电脑打得开）。同 WiFi 可用电脑局域网 IP；正式分享请用公网地址。

## 白话使用说明

1. **学习**：点卡片或「翻面」看答案；「记住了 / 再看」会记在本机；← → 换卡。
2. **卡组**：看列表、改卡组名、跳到某张学习、编辑或删除。
3. **新建/编辑**：填正面、背面、可选标签 → 保存。
4. **分享**：在公网地址下点「复制分享链接」；同学打开即同一套卡。
5. **导入导出**：导出 JSON 备份；导入 JSON / 粘贴文本可换卡组。

## 「改成自己的」3 步（速查）

1. **改内容**：页面新建卡片，或改 `cards.json` 后导入。
2. **改皮肤**：`index.html` 顶部 CSS 变量 `--primary`。
3. **改分享**：发布到公网后，把新链接写进本 README 与 `公网链接.txt`。

更细：`使用说明.md` · `改成自己的.md` · `课堂演示要点.md` · `提示词模板.md`

## 文件列表

- `index.html` — 可运行成品（单文件）
- `cards.json` — 可改示范卡组
- `公网链接.txt` — 当前公网 URL / 认领链接

## 已知限制

- 「记住了 / 再看」只存在本机浏览器，不会随分享链接带走。
- 分享链接过长可能被聊天软件截断；卡组宜精简。
- 直接用 `file://` 打开时可能读不到 `cards.json`（内置示范与 `#c=` 分享仍可用）。
