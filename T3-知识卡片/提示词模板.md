# 提示词模板（帮你用 AI 生成卡组）

把下面模板粘给 ChatGPT / Claude / 通义等，生成后把 JSON 导入本工具。

---

## 模板 A：按教材生成

```
你是小学辅导助手。请根据以下知识点，生成知识卡片 JSON。
要求：
- 输出纯 JSON，不要 markdown 代码块以外的文字
- 格式：{"title":"卡组名","cards":[{"front":"正面问题","back":"背面答案","tag":"标签"}]}
- 共 10 张，front 简短，back 准确易懂
- 适合小学生

知识点：
（在这里粘贴课文 / 单词表 / 考点）
```

---

## 模板 B：单词英译中

```
请把下列英语单词做成知识卡片 JSON：
front=英文，back=中文释义，tag=词性或主题。
输出：{"title":"英语单词","cards":[...]}
单词列表：
apple, book, happy, ...
```

---

## 模板 C：一问一答考点

```
根据下面笔记，每条生成一张「问题 / 答案」卡片。
JSON 字段：title, cards[{front, back, tag}]
笔记：
（粘贴）
```

---

生成后：打开本工具 →「分享/导入」→「从文本导入」粘贴 JSON。
