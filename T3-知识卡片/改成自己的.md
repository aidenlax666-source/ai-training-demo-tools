# 改成自己的（严格 3 步）

适合零基础：只改标注的地方。面向成年学员（自己 / 家人 / 同事记知识点）。

> 对应大纲 **v3.2 模块 8**：扩展菜单 · 最少改 1 张卡或卡组名。官方示范是「v3.2 十模块知识要点」，你可整组换成自己的主题。

---

## 第 1 步：改卡片内容

**方案 A — 页面里加（最快）**

1. 打开网页 →「新建/编辑」
2. 正面写问题，背面写答案，可选标签（如 `模8` 或你的主题）
3. 点「保存卡片」，再去「学习」

**方案 B — 改 `cards.json`（适合练改文件）**

```json
{
  "title": "岗位术语",
  "cards": [
    { "front": "什么是 MVP？", "back": "最小可用产品：先做出能演示的一版", "tag": "产品" }
  ]
}
```

保存后：用本地服务器打开本文件夹 →「分享/导入」→「导入 JSON」选这个文件；或把内容粘进「从文本导入」。

**方案 C — 改 HTML 内置示范**

- 打开 `index.html`，搜索注释：`【改这里②】`
- 改 `BUILTIN.cards` 数组（须与 `cards.json` 保持一致更稳）
