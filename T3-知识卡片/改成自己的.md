# 改成自己的（严格 3 步）

适合零基础：只改标注的地方。

---

## 第 1 步：改卡片内容

**方案 A — 页面里加（最快）**

1. 打开网页 →「新建/编辑」
2. 正面写问题，背面写答案，可选标签
3. 点「保存卡片」，再去「学习」

**方案 B — 改 `cards.json`（适合练改文件）**

```json
{
  "title": "古诗默写",
  "cards": [
    { "front": "静夜思第一句？", "back": "床前明月光", "tag": "唐诗" }
  ]
}
```

保存后：用本地服务器打开本文件夹 →「分享/导入」→「导入 JSON」选这个文件；或把内容粘进「从文本导入」。

**方案 C — 改 HTML 内置示范**

- 打开 `index.html`，搜索注释：`【改这里②】`
- 改 `BUILTIN.cards` 数组

---

## 第 2 步：改皮肤（可选）

- 文件：`index.html` 顶部 `:root`
- 改 `--primary`、`--ok`、`--warn` 等颜色变量

---

## 第 3 步：改分享方式

1. 用 here.now（或同类）发布本文件夹，得到公网 URL。
2. 把 URL 写进 `公网链接.txt` 与 README「课堂演示正式链接」。
3. 课堂演示时先打开公网再「复制分享链接」。

---

## 不要改（除非你知道自己在做什么）

- `#c=` 编码/解码函数
- `localStorage` 的 key 名（改了旧数据对不上）
