# AI 培训示范工具（T1 + T2）

面向 **0 基础成年人实战培训** 的可运行示范：小而专、给自己/家人/少数人用。

| 目录 | 说明 |
|------|------|
| [T1-答题闯关](./T1-答题闯关/) | 口算/知识点答题闯关：可公网分享、比分、错题；**支持知识库 + AI 随机出题**（OpenAI 兼容，自备 Key） |
| [T2-格式转换](./T2-格式转换/) | 固定格式转换 / 批量处理脚本（CSV↔Excel、编码、重命名；**不调用大模型**） |

## T1 公网演示

- **正式链接：** https://lively-mirage-sh6f.here.now/
- 打开 → 家长出题 →「知识库·AI」可粘贴资料并用 DeepSeek 等接口出题（Key 仅存浏览器）
- 无 Key 时可用「规则出题」演示；分享链接只含题目，不含 Key / 知识库全文
- 匿名站约 24h 过期，认领：见 `T1-答题闯关/公网链接.txt`

## 快速开始

### T1 网页
1. 见 `T1-答题闯关/README.md` 与 `公网链接.txt`（公网演示有有效期，请及时认领永久站）。
2. 本地：进入 `T1-答题闯关` 后执行 `python3 -m http.server 8081`，浏览器打开提示地址（不要把 127.0.0.1 当外网分享）。

### T2 脚本
```bash
cd T2-格式转换
bash run_demo.sh          # 最小演示
bash run_scene_a.sh       # CSV↔Excel
bash run_scene_b.sh       # 编码转换
bash run_scene_c.sh       # 批量重命名
```
Windows 请用同名 `.bat`。
