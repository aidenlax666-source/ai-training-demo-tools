# 改成自己的 — 三种场景最短步骤

> **全程不调用大模型 API。** 先进入本文件夹再改配置、再运行。

---

## 场景 A（CSV↔Excel）

1. 改 `config.scene_a.yaml` 的 `input_dir` / `output_dir`  
2. 改 `pattern`（如 `"订单_*.csv"`）；反方向改 xlsx 任务的 `pattern` / `sheet_name`  
3. 放文件 → `bash run_scene_a.sh` 或 `run_scene_a.bat`  
**验收**：输出目录出现对应 xlsx/csv。

**一句**：改路径和 `pattern`，跑 `run_scene_a`。

---

## 场景 B（编码）

1. 改路径  
2. 改 `from_encoding` / `to_encoding` / `pattern`  
3. 跑 `run_scene_b`；用错误编码打开源文件应乱码，打开输出应正常  
**一句**：改编码与 `pattern`，跑 `run_scene_b`。

---

## 场景 C（重命名）

1. 改路径  
2. 改 `prefix` / `sequence` / `sequence_start`  
3. 跑 `run_scene_c`（会清空本场景输出）  
**一句**：改 `prefix`/`sequence`，跑 `run_scene_c`。

---

## 路径示例

```yaml
# macOS / Linux
input_dir: /Users/你/Desktop/待转换
output_dir: /Users/你/Desktop/已转换

# Windows（YAML 里建议正斜杠或引号包起来）
input_dir: "C:/Users/你/Desktop/待转换"
output_dir: "C:/Users/你/Desktop/已转换"
# 也可以写：C:\Users\你\Desktop\待转换（注意反斜杠在部分编辑器需转义）
```
