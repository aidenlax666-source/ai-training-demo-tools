# 提示词：用 AI 生成「同类」固定格式批处理脚本

> 适用：学员想按自己办公室习惯，让 AI **生成一版可长期用的本地脚本**（而不是每次粘贴文件让 AI 手工改）。
>
> 生成后请本地跑通，并删掉任何「调用大模型 API」的代码。

---

## 推荐提示词（直接复制）

```
请写一个 Python 3 本地批处理脚本（不要调用任何 LLM / OpenAI / 其它大模型 API），实现「一次配置、长期使用」的文件格式转换。

【目标】
办公室重复改文件格式：用户把文件放入输入文件夹，根据 YAML 配置自动转换到输出文件夹。

【必须支持】
1. CSV ↔ XLSX 批量互转（可配置分隔符、工作表名、是否表头、源编码 utf-8/gbk/auto）
2. 文本编码批量转换（如 gbk → utf-8），匹配 .txt/.csv
3. 固定规则批量重命名（前缀/后缀/三位序号），可对输出目录文件改名
4. jobs 列表按顺序执行，可组合（先 convert 再 rename）
5. 命令行：python script.py --config config.yaml ；支持 --dry-run
6. 单文件失败只记日志，不中断整批；结束输出成功/失败汇总
7. 输入目录不存在、无匹配文件时给出中文友好提示

【技术约束】
- 依赖仅限：pandas、openpyxl、PyYAML（或标准库能实现的优先标准库）
- 代码含中文注释，函数边界清晰
- 提供 config.example.yaml 示例
- 路径相对配置文件所在目录解析

【交付】
- 完整可运行的 .py
- config.example.yaml
- requirements.txt
- 简短 README（安装、一条命令运行、如何改成自己的 3 步）

请直接给出文件内容，不要只给思路。
```

---

## 缩小范围版（只要 CSV→Excel + 改名）

```
用 Python 写本地脚本：读取 config.yaml，把 input_dir 下所有 *.csv 转成 xlsx 写到 output_dir，
再按 prefix + 序号重命名。支持 --dry-run。不要调用任何在线 AI API。依赖 pandas+openpyxl+PyYAML。
附带示例配置和 3 步「改成自己的」说明。
```

---

## 使用注意

1. 生成后立刻 `pip install` 并用自己的样例跑 `--dry-run`。  
2. 若 AI 擅自加入 `openai` / `requests` 调模型，**删掉**，本场景不需要。  
3. 把跑通的 `config.yaml` 当模板存进公司共享盘，比保存聊天记录更有用。
